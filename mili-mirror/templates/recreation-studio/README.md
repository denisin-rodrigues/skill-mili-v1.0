# Editable Recreation

Projeto React/Vite gerado pelo Mili Mirror a partir de evidências autorizadas.

## Editar

- Textos, links e projetos: `src/content/site-content.ts`
- Cores e tipografia: `src/config/brand.ts`
- Layout e responsividade: `src/styles.css`
- Componentes: `src/App.tsx`
- Evidências: `RECONSTRUCTION-MAP.md`

## Executar

```bash
npm ci
npm run dev
```

Abra `http://127.0.0.1:4174`.

## Classificação

Consulte `recreation-state.json`. Esta entrega é reconstruída/aproximada e não representa recuperação do código-fonte original.
